# `Instrument ++ Reborn`

A fork of the original Instrument++ mod which has the goal of porting this mod to other Minecraft versions, fixing bugs with the original mod and potentially providing compatibility with certain other mods.

Due to the goal of this fork and personal skill level, any new features or new instruments are unlikely.

This mod adds the following 16 noteblock instruments：

| Music Intruments | Pitch | Block                            |
| ---------- | ------- | ------------------------------------ |
| Bassoon    | F#2~F#4 | Basalt and its Variants              |
| Clarinet   | F#3~F#5 | Blackstone and its Variants          |
| Cymbols    | -       | Chains and Iron Bars                 |
| Clean Eletric Guitar | F#3~F#5 | Snow, Snow Blocks and Powdered Snow |
| Distorted Electric Guitar | F#3~F#5 | Netherrack            |
| Erhu       | F#4~F#6 | Coral Blocks and Dead Coral Blocks   |
| French Horn | F#3~F#5 | Any Copper Block                    |
| Guqin       | F#3~F#5 | Moss Carpets and Moss Blocks        |
| Konghou     | F#3~F#5 | Endstone and its Variants           |
| Suona       | F#4~F#6 | Dirt                                |
| Timpani     | F#0~F#2 | Any Nether Brick Block              |
| Trumpet     | F#3~F#5 | Any Cut Copper Block                |
| Tuba       | F#1~F#3 | Gravel                               |
| Viola     | F#3~F#5 | Any Glazed Terracotta Block           |
| Violin     | F#4~F#6 | Any Terracotta Block                 |
| Yangqin     | F#3~F#5 | Amethyst Block and Budding Amethyst |
